# Repository Health Report: RF_Signals_Classifier

## 1. Overview
The **Intelligent RF Signal Classification Pipeline** aims to be an advanced, 4-stage machine learning architecture for Automatic Modulation Classification (AMC). The goal is to use deep learning for robust spectrum sensing.

However, based on the current codebase, the repository is **only partially implemented**. It currently contains robust data ingestion, synthetic generation, preprocessing, and dataset verification tools. The core Machine Learning models and training pipelines (Stages 3 and 4) are **missing**.

## 2. Current Status of the 4-Stage Pipeline

| Stage | Name | Status | Description |
|---|---|---|---|
| **Stage 1** | Ingestion & Dataset Agent | **✅ Implemented** | Both `dataset_agent.py` (for RadioML dataset) and `generate_custom_rf_v4.m` (for synthetic generation) are present and functional. |

| **Stage 4** | Spectrum Cop Decision Engine | **❌ Missing** | No Outlier Detection, Continual Learning (EWC loss), or XAI (Grad-CAM) implementations are present. |

## 3. File-by-File Breakdown

### Data Preprocessing & Pipeline
*   **`dataset_agent.py`**: A robust script that loads the legacy RadioML 2016.10a pickle file, normalizes the I/Q signals (zero-mean, unit-variance), and creates a locked 70/20/10 train/val/test split (saving as `.npy` files).
*   **`dataset_loader.py`**: Provides the `RFSignalDataset` class and `get_rf_dataloader` function. Standardizes the PyTorch loading process using the splits generated by `dataset_agent.py`.
*   **`verify_splits.py`**: A comprehensive analytics script that verifies data integrity, ensures no data leakage across splits, and generates a detailed visualization dashboard (`verification_results.png`).

### Custom Dataset Generation
*   **`generate_custom_rf_v4.m`**: A MATLAB script that generates custom synthetic RF signals (BPSK, QPSK, 8PSK, 16QAM, 64QAM) with realistic channel impairments (fading, Doppler, CFO). Fallbacks are implemented if the Communications Toolbox is unavailable.
*   **`load_mat_dataset.py`**: PyTorch integration script that loads the `.mat` outputs from the MATLAB generator into a PyTorch `TensorDataset`.

### Feature Engineering
*   **`stft_converter.py`**: Handles the Time-Frequency branch of Stage 2. It converts I/Q sequences into Kaiser-windowed 2D power spectrograms for CNN processing.

### Configuration
*   **`requirements.txt`**: Standard Python environment requirements (includes `torch`, `scipy`, `scikit-learn`, `matplotlib`, `numpy`, etc.).
*   **`README.md`**: Outlines the architectural framework but contains claims for features that have not yet been implemented in the code.
